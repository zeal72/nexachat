# NexaChat

> A real-time messaging platform built for fast, clean 
> communication — think WhatsApp meets modern web design.

## What It Does
- Send and receive messages in real time
- Create conversations and chat with other users
- Clean, responsive UI that works on all screen sizes
- Fast message delivery with live updates

## Built With

- JavaScript
- Firebase / Socket.io (replace with what you actually used)
- Tailwind CSS

git clone https://github.com/zeal72/nexachat
